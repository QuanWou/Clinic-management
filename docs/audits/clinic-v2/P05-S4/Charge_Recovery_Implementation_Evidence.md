# Source-charge recovery — implementation evidence (2026-10-02)

This extends the authorized [no-deposit/unsigned baseline](../Delivery_Scope_No_Deposit_Unsigned.md). Source-charge ingestion and recovery never issue a bill, post money, reprice a performed service or release a clinical document.

Medical and Encounter expose their own Billing-delivery state; Billing exposes immutable-inbox reconciliation state and the existing charge count. Responses contain identifiers, status/attempt/error categories only. Each read checks current canonical BILLING permission and clinic/branch RLS. Cashier reads are allowed; retry requires Owner/Manager, reason and Idempotency-Key. Only DLQ can be reset by a new command. Concurrent exact retries commit one receipt/audit effect; replay still checks permission. Changed payload conflicts and a new command cannot reset an active worker or acknowledged event. The original event payload, reviewed order/result, completed Encounter and frozen price remain unchanged.
