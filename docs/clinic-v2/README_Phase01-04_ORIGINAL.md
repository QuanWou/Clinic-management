# Clinic Management V2 — Tài liệu tổng hợp giai đoạn 01–04

Phạm vi: Marketplace + SaaS; phòng khám đa khoa; ngoại trú; thanh toán tại quầy và trực tuyến.

## Thứ tự sử dụng

1. `01_Product_Research/` — nghiên cứu sản phẩm, người dùng, quy trình và quy tắc nghiệp vụ.
2. `02_Product_Requirements/` — PRD, phân quyền, tiêu chí nghiệm thu và quyết định còn mở.
3. `03_Architecture_and_Database/` — microservices, multi-tenancy, ERD, lifecycle, API, event, SQL tham chiếu và migration.
4. `04_UX_UI_and_Prototypes/` — sitemap, wireframe, design system, HTML prototype và UX acceptance.

Mở `04_UX_UI_and_Prototypes/index.html` trong trình duyệt để xem prototype.

## Trạng thái

Đây là tài liệu thiết kế đề xuất, không phải hệ thống đã triển khai. Các vấn đề trong Decision Log và compliance cần xác nhận; V1 Gap Analysis chưa phải audit source. SQL chỉ là bản tham chiếu, không chạy trực tiếp trên database V1. Chưa thay đổi source/database.

`MANIFEST_SHA256.txt` chứa SHA-256 từng file để kiểm tra toàn vẹn.
