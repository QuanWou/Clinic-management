# encounter-service

Tiếp nhận, hàng đợi và lượt khám. Service Spring Boot độc lập trong hệ thống Clinic Management.

Xem [kiến trúc](../../docs/ARCHITECTURE.md) và [vận hành](../../docs/OPERATIONS.md). Chạy toàn bộ hệ thống bằng `scripts/start.ps1` từ root; cấu hình và bí mật không nằm trong source.

Migration đã áp dụng được giữ nguyên để bảo toàn database hiện có. Kiểm thử cần database ngoài phải dùng sandbox riêng, không dùng database vận hành.
